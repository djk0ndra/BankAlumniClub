# Встреча выпускников НГУ и ФМШ · Москва · 28.11.2026

Статический лендинг регистрации: `index.html`, `styles.css`, `script.js`, папка `assets/`.
Сборка не нужна — загрузите содержимое репозитория в корень хостинга.

## Что заменить перед публикацией

| Что | Где | Как |
|---|---|---|
| Постер | `assets/poster.jpg` | Положить файл с тем же именем, пропорция 4:5. Нет файла → показывается заглушка |
| QR-код | `assets/qr.png` | Квадрат от 560×560 px. Нет файла → заглушка «Здесь будет QR-код» |
| Endpoint формы | `script.js`, константа `FORM_ENDPOINT` | Адрес формы Formspree вида `https://formspree.io/f/xxxxxxxx`. Пока не задан — демо-режим без отправки |
| Адрес сайта для соцсетей | `index.html`, теги `og:url`, `og:image`, `twitter:image` | Заменить `https://example.com/` на реальный домен |
| Превью для соцсетей | `assets/og-image.jpg` | 1200×630 px |

Форма отправляет поля `name`, `email`, `phone`, `graduation_year`, `faculty`, `comment` JSON-запросом (POST), поэтому подойдёт любой сервис, принимающий такой формат.
